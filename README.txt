AUTOREPAIR PWA V1

Това е първа PWA версия за Windows + iPhone.

За локален тест: използвай VS Code с Live Server или друг HTTP сървър.
За iPhone: приложението трябва да е достъпно през HTTPS. В Safari отвори адреса и избери Share -> Add to Home Screen.

Следваща стъпка: онлайн база, вход, VIN, ремонтни процедури и реални проверени технически данни.
